<h1 align="center">HelloWorld.ie</h1>

<p align="center"><strong>When buyers ask AI for a shortlist, be on it.</strong></p>

HelloWorld is an Irish Answer Engine Optimisation (AEO) studio, led by Bryan Hurley. It finds where
a company stands in ChatGPT, Google's AI Overviews, Copilot and Perplexity, and gets it named and
recommended. The name comes from the first line every program prints: the moment something says
hello to the world.

This account holds the code behind that work: the website and its audit platform, free tools,
experiments and a few games.

## Every project in one place

The repository hub at **https://helloworldie.github.io** shows every project as a card and as a
building in a small 3D city, with pictures, demos, guides and the code. Most repos are private.
Signed out, the hub shows the public ones. Sign in with GitHub to see everything your account can
read.

[![The hub's one-screen dashboard, with example data](https://helloworldie.github.io/hub/cover.jpg)](https://helloworldie.github.io/)
